# Neural Network Expert System

This project is an interactive Knowledge-Based System that helps the user build neural network layers.

The system asks the user about layer parameters, stores answers as facts, and applies expert rules to infer:

- input shape
- output shape
- weight matrix shape
- layer compatibility
- needed transformations

## Current implemented layer

- Embedding

## Main constraints

- No search algorithm
- No neural network training
- No real dataset loading
- No PyTorch
- No TensorFlow
- Reasoning is done using Experta Facts and Rules
